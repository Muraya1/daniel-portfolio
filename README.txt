DANIEL MURAYA — PORTFOLIO WEBSITE

Files:
- index.html: responsive portfolio website with embedded CSS and JavaScript
- resume.html: printable resume (Print / Save as PDF)

How to preview:
1. Unzip the folder.
2. Double-click index.html in any modern browser.

How to publish:
1. Upload index.html and resume.html to your hosting website's public_html directory (or a separate subdomain's document root).
2. Ensure index.html is the default homepage.
3. Enable HTTPS for your domain.

Before publishing:
- Verify LinkedIn and GitHub links.
- Review experience and project descriptions for accuracy.
- Add screenshots and any additional SaaS projects as you develop them.
- The FileGuard application remains on its existing URL; this portfolio links to it without replacing it.
- Email contact opens the visitor's email app; it does not require backend code.
